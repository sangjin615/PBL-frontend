# WBS 세부 기능 목차 ("-" 항목은 핵심 기능명 그대로 사용)

## 커리큘럼 관리
- 커리큘럼 탐색 — 전체/카테고리별 목록과 검색, 정렬 제공
  - 커리큘럼 조회 및 검색 — 키워드·필터로 공개 커리큘럼 찾기
  - 커리큘럼 추천 — 사용자 맞춤 추천 목록 제공
- 커리큘럼 생성 — 새 커리큘럼 기본 정보와 강의 구성 등록
  - 커리큘럼 생성 — 제목·설명·난이도·강의 묶음 생성
- 커리큘럼 수정 — 메타·구성·공개상태 등 변경
  - 커리큘럼 메타데이터 관리하기 — 제목/설명/태그/썸네일 수정
  - 강의(순서/소속) 변경하기 — 포함 강의 정렬·이동
  - 외부 강의 링크(연결/해제)하기 — 외부 콘텐츠 연결 관리
  - 커리큘럼(공개/비공개) 상태 설정 — 노출 범위 전환
- 커리큘럼 삭제 — 권한 검증 후 커리큘럼 제거
  - 커리큘럼 삭제 — 연관 데이터 점검 후 삭제 처리
- 커리큘럼 수강 관리 — 신청/조회/취소/진도 관리
  - 커리큘럼 수강 신청 — 한 클릭으로 학습 등록
  - 수강 중인 커리큘럼 조회 — 내 수강 목록과 진행률 확인
  - 커리큘럼 수강 취소 — 수강 해제 및 상태 변경
  - 커리큘럼 진도 추적 — 완료율과 학습 이력 저장
- 피드백 관리 — 사용자 반응과 신고 처리
  - 작성물 추천/비추천하기 — 좋아요/싫어요 집계
  - 작성물 신고 및 제재하기 — 신고 접수·관리자 조치
  - 리뷰 관리하기 — 별점·텍스트 리뷰 수집/관리

## 강의 저작관리
- 강의 생성 — 유형 선택 후 단계별 작성·저장
  - 강의 생성 — MARKDOWN/PROBLEM/VIDEO 등 생성
- 강의 조회 — 내가 만든 강의 목록·상세 보기
  - 강의 조회 — 필터/정렬로 빠르게 찾기
- 강의 수정 — 내용과 설정 전반 편집
  - 강의의 메타데이터 관리 — 제목/카테고리/난이도 등 수정
  - 슬라이드 페이지 생성/조회/수정/삭제 — 마크다운 기반 슬라이드 관리
  - 사진 업로드/조회/삭제 — 이미지 자산 추가·관리
  - 동영상 업로드/조회/삭제 — 강의 영상 파일 관리
  - 텍스트 작성/조회/수정/삭제 — 본문 텍스트 편집
  - 코드 작성/조회/수정/삭제 — 예제 코드 작성과 변경
  - 강의 공개/비공개 설정 — 노출 여부 토글
- 문제 저작·관리 — 문제형 강의 전용 CRUD
  - 문제 조회 — 문제 목록 확인
  - 문제 생성 — 설명·입출력·테스트케이스 등록
  - 문제 수정 — 제약·테스트케이스 변경
  - 문제 삭제 — 필요 시 문제 제거
- 강의 삭제 — 종속성 확인 후 강의 제거
  - 강의 삭제 — 커리큘럼 포함 여부 점검 후 삭제

## 강의물 학습
- 강의물 조회 — 텍스트/슬라이드/영상 등 콘텐츠 학습
  - 강의물 조회 — 반응형 뷰로 콘텐츠 표시
- 답안 업로드 — 문제 풀이 코드 제출
  - 답안 업로드 — 에디터/파일로 제출 지원
- 답안 채점 — 테스트케이스 자동 채점
  - 답안 채점 — 실행 결과·점수 확인
- 오답 해설 — AI 기반 풀이 가이드 제공
  - 오답 해설 — 스트리밍 해설로 단계별 안내
- 학습 히스토리 불러오기 — 이전 작업 재사용
  - 학습 히스토리 불러오기 — 제출 기록·코드 복원
- 개발 환경 관리 — 실행·디버깅 도구 제공
  - 종속성 컨테이너 제공 — 언어별 런타임 제공
  - 에디터 제공 — Monaco 기반 코드 편집기
  - 결과 콘솔 및 시뮬레이터 제공 — 출력·상태 확인
  - 디버거 기능 제공 — 중단점·단계 실행 지원
  - 변수 탐색기 제공 — 현재 스코프 변수 조회

## 사용자 관리
- 사용자 권한 관리 — 역할 기반 접근 제어 설정
  - 사용자 권한 관리 — user/admin 권한 부여·검증
- 사용자 인증 관리 — 계정 생애주기 관리
  - 회원가입 — 계정 생성 및 중복 검사
  - 회원 탈퇴 — 계정 비활성화 및 데이터 처리
  - 로그인 — 자격 검증 후 세션 발급
  - 로그아웃 — 토큰 삭제 및 세션 종료
- 사용자 정보 관리 — 프로필과 통계 확인/수정
  - 사용자 정보 관리 — 기본 정보·학습 현황 관리

## Q&A 게시판 관리
- 게시글 관리 — 질문/토론 글 CRUD
  - 게시글 생성 — 제목·내용·카테고리로 등록
  - 게시글 탐색 — 검색·필터·정렬로 찾기
  - 게시글 수정 — 작성자 권한으로 내용 변경
  - 게시글 삭제 — 작성자/관리자에 의한 삭제
- 댓글 관리 — 답변·대댓글 운영
  - 댓글 생성 — 답변/대댓글 작성
  - 댓글 탐색 — 중첩 구조로 목록 조회
  - 댓글 수정 — 인라인 편집 지원
  - 댓글 삭제 — 소프트/하드 삭제 선택
- 피드백 관리 — 품질 유지와 질서 관리
  - 작성물 추천/비추천하기 — 좋아요 기반 정렬
  - 작성물 신고 및 제재하기 — 신고 접수·처리
